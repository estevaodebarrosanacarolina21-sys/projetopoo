# Pacote de atividade

Este pacote foi criado para iniciar a estrutura da atividade do projeto.

## Estrutura
- `Atividade.java`: classe principal com exemplo de cadastro de usuários por perfil.

## Perfil suportado
- Cliente
- Lojista
- Profissional autônomo
- Parceiro institucional
- Administrador

## Como executar
```bash
javac atividades/atividade/Atividade.java
java -cp atividades/atividade atividade.Atividade
```
